# CSS-225 – Module 8: Booleans and Selection

**Author:** Abdyrakhman Raiapov  
**Course:** CSS-225, National Louis University  
**Date:** November 15, 2026

This folder contains my Module 8 Lab Activity programs. Every program makes a
decision with Boolean expressions (`==`, `>`, `<`, `in`, `and`, `or`, `not`) and
selection statements (`if` / `elif` / `else`). Each solution is written as a function.

| Problem | File | What it does |
|---|---|---|
| 1 | `Problem1_EqualInputs.py` | Reads two inputs and prints whether they are equal (numbers are compared as numbers, so `5` equals `5.0`). |
| 2 | `Problem2_SumCompare.py` | Reads two numbers and prints whether their sum is greater than, less than, or equal to 10. |
| 3 | `Problem3_FiveInList.py` | Uses the `in` operator to print whether the value 5 is in a list. |
| 4 | `Problem4_LeapYear.py` | Returns `True` for a leap year: divisible by 4, except century years not divisible by 400. |
| 5 | `Problem5_CharacterTasks.py` | Checks whether a game character has all items for a task and no status debuff that blocks it (Tasks 1–3). |

## How to run

```
python Problem2_SumCompare.py
```

Python 3 is required. Problems 1 and 2 ask for input in the console; invalid
numbers are rejected with a message instead of crashing the program.
